# Maintainer handoff

Start with the widget README and [CODE_STRUCTURE.md](CODE_STRUCTURE.md). [STORAGE.md](STORAGE.md) explains state and cleanup. [MAINTENANCE.md](MAINTENANCE.md) covers changes and release checks. [TROUBLESHOOTING.md](TROUBLESHOOTING.md) lists failure symptoms.

The widget is intentionally generic: available layers are discovered from the connected map. Do not add organization-specific layer names, URLs, or comparison subjects to the code or default configuration.

Target: Experience Builder 1.21 with Maps SDK 5.1. See `docs/VALIDATION.md` for the distinction between local verification and the final EB installation checks.
